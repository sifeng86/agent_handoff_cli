# Ownership / CAS Acceptance Audit (A01–A10)

Scope: Design v1.2 §20.1, audited against complete relevant test bodies and the live ownership, CAS, and Plan/takeover evidence records. The recorded environment is Ubuntu 24.04 on a Microsoft WSL2 kernel. `proven_local` means the required behavior is asserted against the local bare-Git fixture; `proven_hosting` means the requirement-level behavior is also present in an executed hosting run; `incomplete` means an acceptance assertion is materially missing. A hosting result is not required where the specification does not require it.

## Audit closure and remaining scope

- A05 now covers the exact same-session capability-loss case, explicit rejection, no mutation and explicit takeover. It is local evidence.
- A06 now asserts old/new session-ID inequality locally and in the renewed GitHub run. Its scoped [evidence record](ownership-closure-evidence.json) includes independent branch cleanup/mainline confirmation.
- A10's runtime no-retry behavior has a strong local fault-injection test. Hosting CAS evidence is narrower; a live runtime race is not required by §20.1 and is not claimed here.
- A02 hosting race and A07/A08 hosting checks are sequentially scoped as documented; they do not establish an in-flight old-writer transport race.
